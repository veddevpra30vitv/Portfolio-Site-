Projects

Selected case studies.

Project 01

Ecom Easy

Ecom Easy is a full-stack e-commerce project that helped me understand how a shopping experience comes together across front-end interfaces and backend systems. The project covers browsing products, adding items to a cart, and managing the flow from product selection to a cohesive purchase journey.

In practice, this meant working with product data, user interactions, component structure, and the flow of information between the interface and the database. I was able to see how backend integration, data modelling, and front-end decisions influence the overall experience for an online store.

Next.js MongoDB Node.js Full stack
Live demo Github Repository

Project 02

WatchiT

WatchiT is a real-time watch-party platform where friends can gather in a shared room using a party code. Hosts control synchronized video playback while everyone can chat, react, and discover videos together.

Built with Next.js, Socket.IO, and MongoDB, it brings together live room communication and persistent party data. The project explores playback synchronization, real-time collaboration, and handling different video sources in one full-stack application.

Next.js Node.js Socket.IO MongoDB Real-time YouTube API
Live demo GitHub repository

Project 03

Spotify Songs Analysis

This project explored how different music characteristics may relate to a song’s popularity by examining dataset patterns and visualizing the results. It was a practical introduction to data analysis and to the process of turning raw information into understandable observations.

I worked with Python, Pandas, and Matplotlib to clean data, organize features, and plot relationships. The emphasis was not on proving causation, but on understanding which variables might correlate with popularity, how to interpret them carefully, and how to present findings in a meaningful way.
